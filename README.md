# AI Smart Compliance | الامتثال الذكي

**AI-Powered Facility Risk Scoring & Compliance Intelligence Dashboard**

وزارة السياحة | Ministry of Tourism — Kingdom of Saudi Arabia

## Overview

AI Smart Compliance provides AI-driven risk scoring, compliance monitoring, and inspection prioritization for 300+ licensed tourism facilities across Saudi Arabia, aligned with Vision 2030 quality targets.

## Features

- **AI Risk Scoring** — Claude-powered facility risk assessment (0–100)
- **Inspection Dashboard** — KPIs, priority queue, risk distribution
- **Geo-Intelligence** — Interactive heatmap with violation density
- **Violation Classification** — AI-powered bilingual classification
- **Smart Checklists** — AI-generated inspection checklists
- **Reports** — CSV/PDF export with CONFIDENTIAL watermark
- **Bilingual** — Full Arabic (RTL) and English support

## Tech Stack

React + TypeScript + Tailwind CSS | Node.js + Express | PostgreSQL + Prisma | Claude API | Recharts | Leaflet.js
